# AI Prompt Lab

Laboratorio personal de Prompt Engineering, evaluación de respuestas de IA y mejora de prompts.

## Objetivo

Documentar casos prácticos donde se analizan respuestas generadas por IA, se detectan problemas, se mejoran prompts y se comparan resultados.

## Casos

- Caso 01 — Marketing + alucinaciones
- Caso 02 — Soporte técnico + incertidumbre
- Caso 03 — Recolección de requisitos
